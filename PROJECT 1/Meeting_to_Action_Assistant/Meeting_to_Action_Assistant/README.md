# M1-P2: AI-Powered Meeting-to-Action Assistant

A terminal application that reads a meeting transcript, sends it to the **Google Gemini API**, and turns it into structured meeting information: summary, decisions, tasks with owners and deadlines, follow-up actions, and clarification questions for anything missing or ambiguous.

## Features

- Accepts a transcript typed/pasted in the terminal, loaded from a `.txt` file (`--file`), or passed with `--text`
- Concise meeting **summary** and clearly agreed **decisions**
- **Tasks** with **responsible person** and **deadline**
- Detects **incomplete or ambiguous** action items (no owner, no deadline, vague wording)
- Lists **clarification questions** for every gap (generated by the AI and completed by code)
- **Follow-up actions**
- **Anti-hallucination safeguards**: strict prompt + code-level check that removes any owner or deadline that does not literally appear in the transcript
- Structured **JSON** output, a readable terminal report, and saved `.json` + `.txt` files in `output/`
- Input validation, retry with back-off, model fallback and friendly error messages

## Technologies used

Python 3, Google Gen AI SDK (`google-genai`), Gemini API (JSON output mode), `python-dotenv`, and the Python standard library (`argparse`, `json`, `re`, `textwrap`, `pathlib`). No database, Docker or web frontend is needed.

## Installation (Windows 10/11, VS Code terminal)

Requires Python 3.10 or newer. Open the VS Code terminal (**Command Prompt** profile recommended) and run:

```bat
cd AI_College_Projects\Meeting_to_Action_Assistant
python -m venv venv
venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.example .env
notepad .env
```

## Getting and configuring a Gemini API key

1. Open <https://aistudio.google.com/apikey> and sign in with a Google account.
2. Click **Create API key** (choose or create a project) and copy the key.
3. In this project folder, copy `.env.example` to `.env` (the `copy` command above does this).
4. Open `.env` in Notepad and replace the placeholder:

```
GEMINI_API_KEY=AIza...your-real-key...
```

5. Save the file. The key is read with `python-dotenv`; it is never written in the code. Never share or commit your `.env` file.

The default model is set in `config.py` (`MODEL_NAME`). To use a different Gemini model, add `GEMINI_MODEL=<model-name>` to `.env`. If the chosen model is unavailable, overloaded or out of quota, the app automatically tries the models listed in `FALLBACK_MODELS` in `config.py`.

## How to run

```bat
REM 1) Use the included sample transcript
python main.py --file samples\sample_meeting.txt

REM 2) Interactive menu (type/paste a transcript, or load a file)
python main.py

REM 3) Pass text directly
python main.py --text "Rahul will complete the frontend by Friday. Priya will work on the database. We need to finalize the documentation, but we haven't decided who will do it."
```

In the interactive menu, paste the transcript and type `END` on a new line (or press `Ctrl+Z`, then Enter) to finish.

Reports are saved to the `output/` folder as `meeting_report_<timestamp>.json` and `.txt`.


## How hallucinations are reduced

1. The system prompt forbids inventing names, deadlines, tasks or decisions and requires `null` for anything not stated.
2. Low model temperature (`0.1`) and JSON output mode.
3. `src/validators.py` verifies every owner and deadline against the transcript text; anything not found is removed and turned into a clarification question.

## Troubleshooting (Windows)

| Problem | Fix |
|---|---|
| `python` is not recognised | Install Python 3.10+ from python.org and tick **Add python.exe to PATH**, or use `py` instead of `python`. |
| PowerShell blocks `venv\Scripts\Activate.ps1` | Use **Command Prompt** (cmd) instead, or run `Set-ExecutionPolicy -Scope Process Bypass` first. |
| `GEMINI_API_KEY is missing` | Make sure the file is named exactly `.env` (not `.env.txt`) and contains your real key. In Notepad choose *Save as -> All files*. |
| HTTP 429 / quota errors | Free-tier rate limit. The app retries automatically; wait a minute and run again. |
| `Model not found` | Set `GEMINI_MODEL` in `.env` to a model your key can use (see <https://ai.google.dev/gemini-api/docs/models>). |
